# IBM Data Analyst Capstone Project

Final capstone project completed as part of the IBM Data Analyst Professional Certificate on Coursera.

## Project Overview

This project analyzes developer and technology trends using data from the Stack Overflow Developer Survey.

The analysis covers:
- Current and future programming language trends
- Current and future database trends
- Technology usage
- Developer demographics
- Data cleaning and exploratory data analysis
- Dashboard visualizations and business insights

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- IBM Cognos Analytics
- Microsoft PowerPoint

## Final Project

The final report presents the methodology, analysis, visualizations, dashboard insights, findings, implications, and conclusions from the capstone project.

The submitted final project received a score of **100%**.
