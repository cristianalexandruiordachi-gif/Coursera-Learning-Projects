# Simple Interest Calculator

A Bash calculator that calculates simple interest given principal, annual rate of interest and time period in years.

## Inputs

- Principal amount (p)
- Annual interest rate as a percentage (r)
- Time period in years (t)

## Calculation

Simple interest = p * r * t / 100

## Usage

Run: bash simple-interest.sh

Example: principal 1000, annual rate 5, time 2 years gives simple interest 100.
